## Retained diagnostics and limits

An initial control diagnostic could not move the captured relative pointer using the automation
coordinate actions. Its destination warning correctly identified a non-session app; no text was
sent there. Escape, paused-agent refusal and handback passed, and cleanup completed normally.
A subsequent exact `cover` placement was refused by TextEdit, with normal cleanup. Neither attempt
is recorded as a passing full Viewer run. The successful run used standard `fit` placement and
confirmed the session-app destination before typing. No runtime fix for automation relative-pointer
movement or TextEdit exact-cover sizing is claimed.

During static-document inspection the Viewer briefly labelled the stream stalled; later updates
and the typed marker were delivered. The separate changing Metal fixture passed sustained-frame
checks. The label is not evidence that unchanged content was animating. No blanket guarantee of
continuous frame delivery for static or occluded apps is claimed.

Viewer hosted inside a virtual display remains unsupported. The previously disclosed synthetic
Chrome animation and intermittent Accessibility discovery issues remain under investigation;
discovery continues to fail closed. These results do not establish compatibility with other OS
builds or independent human mouse-gesture coverage.

Private evidence is retained under `.artifacts/release-1.0.3/`: candidate verification, source CI
identifiers, matrix, native-probe/frame/resource reports, interactive control evidence, failed
fixture diagnostics, pre/post host inventories and rollback results. Raw screenshots, Accessibility
content, controller leases and user data are excluded from this public record.
