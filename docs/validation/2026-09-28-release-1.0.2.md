# SpaceO 1.0.2 release qualification

Status: superseded before publication by 1.0.3 preparation; immutable tag/artifact retained.

The owner requested a new release and supervised completion after authorizing live performance
tests and controlled recovery on this reserved Mac. This is implementer qualification on the
existing graphical login, not independent or fresh-user testing. Tester: the Codex implementer
agent operating for GitHub account `ParthJadhav`; release owner: `ParthJadhav`. Publication must use the exact
signed, notarized candidate after verification. No prior release evidence is relabeled.

Scope: native apps and Chromium on Apple Silicon, with Viewer on a physical display. Managed
Electron launch and Viewer hosted on a virtual display remain unsupported. The performance
changes and unresolved diagnostic limitations are disclosed in the release notes.

Source preparation, live qualification, exact candidate identity, distribution checks, rollback,
publication and public-download verification will be recorded here as they complete.

The full MCP computer-use matrix ran against the staged signed 1.0.2 CLI, using an isolated
matching daemon. It passed 36/36 checks with zero failed, blocked or skipped results (44 tool
calls). Native TextEdit and Chromium placement, input, captures and isolation were exercised;

## Viewer qualification hold

The first signed native Metal diagnostic failed its required sustained-frame check and is not
passing qualification evidence. Its cleanup restored topology; resource samplers reported no
failure. The fixture completed 900 GPU submissions with zero failures, but reported its window
occluded. Viewer consumers stopped and restarted capture as expected, while sustained visible
frame delivery remained absent.

A separate focused inspection of the signed Viewer confirmed the correct `release-viewer`
session selected, but its canvas showed an external authentication surface instead of the
owned TextEdit document. The diagnostic was stopped for cleanup without attempting control or
bypassing authentication. Publication was held pending normal owner unlock and completion
of the exact-candidate Viewer checks. Earlier passing source/matrix results remain separately
identified; this failed Viewer attempt is not relabeled as a pass.

## Superseded before publication

Packaging review found that the signed DMG included installation examples pinned to 1.0.1.
The waiting publication workflow was cancelled. Neither the immutable 1.0.2 tag nor its signed
artifact was changed. Version 1.0.3 will carry corrected installation guidance and a release
configuration check that rejects an example version differing from VERSION.

A default-daemon session inventory was not retained before the 1.0.2 attempts, so it is not
retroactively claimed. A fresh zero-session baseline is retained for the 1.0.3 work and will be
compared after its exact-artifact tests. See the [1.0.3 record](2026-09-28-release-1.0.3.md).
